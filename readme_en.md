To run the script or application, follow the steps below:

Required for both:
    Have Python 3 installed:
    Have pip installed
    Create a virtual environment with Python
        On Windows: python -m venv .venv
        On Linux: python3 -m venv .venv
    Activating the virtual environment
        On Windows: .venv\Scripts\activate
        On Linux: source .venv/bin/activate
    Deactivate the virtual environment
        On Windows: .venv\Scripts\deactivate
        On Linux: deactivate

Required to run the script:
    pip install pywhatkit
    (Open the main.py file)

Required to run the script with the CTK interface:
    pip install customtkinter pywhatkit
    (Open ctk_main.py and select the Python option and the Python version number installed on your computer.)

To change settings such as tab closing time and the time it will send, and more, use the wiki in the repository of the pywhatkit library creator:
Link: https://github.com/Ankit404butfound/PyWhatKit/wiki

---
Note: For the script to run correctly and without errors, it must be run in the main monitor.
