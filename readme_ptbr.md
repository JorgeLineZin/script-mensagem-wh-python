Repositório Github: https://github.com/JorgeLineZin/script-mensagem-wh-python.git

Para rodar o scrip ou a aplicação siga os passos abaixo

Necessário para ambos :
    Ter o python 3 instalado
    Ter o pip instalado
    Criar um ambiente virtual com o python
        No Windows: python -m venv .venv
        No Linux: python3 -m venv .venv
    Ativando o ambiente virtual
        No Windows: .venv\Scripts\activate
        No Linux: source .venv/bin/activate
    Desativar o ambiente virtual
        No Windows: .venv\Scripts\deactivate
        No Linux: deactivate

Necessário para rodar o scrip:
    pip install pywhatkit
    ('Abra a arquivo main.py')

Necessário para rodar Scrip com a interface CTK:
    pip install customtkinter pywhatkit
    ('Abra a arquivo ctk_main.py e escolha pela opção python e o número da versão do python instalada no seu computador')

Para alterar as configurações como tempo de fechamento da aba horário que sera enviada e mais, utilize a wiki no repositório do criador da biblioteca pywhatkit
Link: https://github.com/Ankit404butfound/PyWhatKit/wiki

Observação: para que o script seja rodado da maneira certa e sem erros deve ser rodado no monitor principal.
